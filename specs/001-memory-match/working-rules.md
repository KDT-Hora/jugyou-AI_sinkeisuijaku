# AI作業条件（開始時にAIへ渡し、復唱させる）

## 進め方
- テストファースト：実装前に失敗テストを書き、落ちることを確認する
- 1回の作業は1つのTaskだけ。終わるごとに実物を取得して報告する
- SPECにないルールは追加しない。必要なら先にInterview/SPECへ戻る

## 変更範囲
- 変更してよいのは対象Taskのファイルとシーンだけ
- パッケージ追加・版更新・外部アセット導入はしない

## 検証と正直さ
- 状態を直接書き換えて「動いた」ことにしない
- 裏のデータ（絵柄）を覗いてプレイしない
- 失敗は成功として報告しない。部分的に進んだら現状を再取得してから続ける
- 区切りでシーンとプロジェクトを保存し、入力とPlayを残さない
