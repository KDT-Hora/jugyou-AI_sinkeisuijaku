# Verification: 神経衰弱（2人対戦・CPU対戦）

**日付**: 2026-11-24　**環境**: Unity 6000.6.4f1、unity-cli 0.19.1（ブリッジ 0.19.1、`versionCheck: match`）

## 方法

- **根拠は2種類**：状態（`get_component_values` の `Game/MemoryGame`）と画面（Game View の画像 `evidence/*.png`）。
- **入力**：`unity-cli raw input_keyboard`（矢印、Space、Enter、R）のみ。状態の直接書き換えはしていない。例外は設定値（`UseSeed`、`Seed`）で、Play中に設定画面の前でCLIから設定した（spec が許す「シード固定」）。
- **覗き見なし**：AI プレイヤーは、画面に表示された（表向き・取得済みの）絵柄だけを記憶した。`FaceSymbols` は裏向きを `?` で返すため、裏の絵柄は読めない。
- **画像の確認方法**：画像を開いて、手番表示、取得数、勝者表示、カードの色と文字を目で読んだ。画像を取っただけでは確認済みとしていない。
- **テスト用の道具**：外れ表示（1.0秒）の最中に操作する確認だけ、`Time.timeScale` を 0.2 に下げて実時間を延ばした（終了後に 1.0 へ戻し、戻ったことを確認）。ルールや状態は変えていない。
- スクリプト：シナリオ A（人間2人、通しプレイ、シード1234）109項目、シナリオ B（CPU）17項目。すべて合格。

## 判定の凡例

確認済み＝状態と画面で確認した。未成立＝期待どおりでなかった。未確認＝確認できていない。

## 実証の中で見つかった問題と対応

| 問題 | 原因 | 対応 |
|---|---|---|
| キー入力がゲームに届かない | ① Editor に フォーカスがないとゲームループが止まる、② Input System がフォーカスなしのキーボードを無効にする、③ unity-cli の仮想キーボードは `wasPressedThisFrame` を返さない | `MemoryGame` の起動時に `runInBackground=true` と Input System の背景入力設定（実行時のみ）を設定。キーは `isPressed` の変化で判定する方式に変更。 |
| 右側の操作ヒントが画面端で切れた | 1行が長かった | 3行に分けた。 |
| 検証スクリプトの失敗（最初 11件、次に 4件） | 外れ表示の1.0秒を競って3枚目を押す手順が、表示終了後に実行され、実際に次の手番のカードをめくった。ゲームの不具合ではない | `timeScale` を一時的に下げて表示時間を延ばし、手順を決定的にした。3回目で 109件すべて合格。 |
