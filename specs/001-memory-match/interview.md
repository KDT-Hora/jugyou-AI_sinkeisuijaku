# Interview 決定メモ
| 質問 | 人間の回答 | 決定理由 | SPEC反映先 |
|---|---|---|---|
| 盤面（枚数/ペア数） | 未決（例: 12枚=6ペア, 4列x3行） | | |
| ミス上限 | 未決（例: 5） | | |
| スコア配分 | 未決（例: 成立+100 / ミス-10, 下限0） | | |
| シード固定で開始できるか | 未決 | | |
| Q1 対戦の人数・組み合わせ | 人間2人（ローカル交代）＋CPUへの切り替え可 | 要件「二人以上・CPU戦含む」を最小で満たす | spec: プレイヤー設定 |
| Q2 成立時の手番 | 成立したら同じプレイヤーが続行、外したら交代 | 標準ルール | spec: ターン規則(M3) |
| Q3 盤面 | 24枚（12ペア、6列x4行） | 対戦で勝敗が付きやすい枚数 | spec: M1 初期状態 |
| Q4 勝敗 | 取得ペア数が多い方が勝ち、同数は引き分け。ミス上限・減点は廃止 | 対戦ではミス上限が不要 | spec: M5 終了条件 |
| Q5 CPUの強さ | 弱・普通・強の3段階から選択 | 遊び幅を持たせる | spec: CPU仕様（記憶確率は次質問） |
| Q6 CPU記憶確率 | 弱25%／普通60%／強100% | 差が体感できる | spec: CPU仕様 |
| 以降（推奨で一括決定） | | | |
| Q7 乱数 | シード指定で配置とCPUの挙動を再現できる。未指定は毎回ランダム | AI検証に必要（スライド9） | spec: M1, テスト |
| Q8 操作 | 矢印キーでカーソル移動、Spaceでめくる、Rで再開。人間2人は同じキーボードを交代で使う | スライド7のM2/M6を踏襲 | spec: M2, M6 |
| Q9 外れ時 | 2枚目を表にして1.0秒見せてから両方裏へ戻し、手番交代。その間は入力を受け付けない | 曖昧さ回避（スライド14） | spec: M3 |
| Q10 CPU手番 | CPUは0.8秒間隔で1枚ずつめくる。カーソルは使わず直接指定 | 人間が見て追える速さ | spec: CPU仕様 |
| Q11 開始設定 | 開始前の設定画面で、各プレイヤーを「人間／CPU弱／CPU普通／CPU強」から選ぶ。既定はP1人間、P2 CPU普通 | 要件「CPU戦含む」 | spec: プレイヤー設定 |
| Q12 表示 | 現在の手番、各自の取得ペア数、残りペア数、終了時の勝者／引き分け | 状態をCLIで取得できる名前にする | spec: M1, M5 |
| Q13 範囲外 | 効果音、オンライン、ランキング、外部アセット、実行ファイルのビルド。絵柄は色と記号 | スライド7 | spec: 範囲外 |
| 後半の1機能 | 制限時間を追加する | ユーザーが選択 | spec: User Story 4、FR-019〜023 |
| Q14 制限時間の長さ | ゲーム全体で180秒（既定）。設定画面では変更しない | CPU同士の通しプレイが約60〜80秒で終わるため、人間の対戦でも途中で切れにくい長さ | spec: FR-019 |
| Q15 時間切れの勝敗 | その時点の取得ペア数で決める。同数は引き分け | M5と同じ規則で新しいルールを足さない | spec: FR-020 |
| Q16 時間切れの瞬間 | 取得済みでない表向きのカードは裏に戻し、手番交代はしない。外れ表示中も時間は減る | 曖昧さ回避（スライド14） | spec: FR-021、Edge Cases |
| 追加機能：マウス操作 | カード選択（ホバーで枠が移る、左クリックでめくる）と設定画面（行クリックで切替、STARTクリックで開始）。キーボードは残す。Rはキーのみ | ユーザーの依頼「マウスカーソルで選択してできるように」。設定画面も含めないとマウスだけで始められないため。再開ボタンは範囲を広げないため作らない | spec: User Story 5、FR-024〜027 |
